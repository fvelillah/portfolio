## 🚀 Key Featured Projects

1. **Multi-Agent Fleet Management** — Real-time telemetry, routing, and dynamic collision avoidance for autonomous AGVs/AMRs in industrial automated warehousing.
2. **Industrial Anomaly Detection with Autoencoders** — Deep learning defect inspection using convolutional autoencoders in PyTorch on MVTec AD dataset.
3. **SCARA 3-DOF Robotic Arm (RR-P)** — Denavit-Hartenberg kinematics, 5th-order polynomial splines for zero-jerk Cartesian trajectory planning, and physical embedded controller validation with interactive video telemetry.
4. **Autonomous Ground Vehicle with ROS2 & Micro-ROS** — Dual-core architecture (Raspberry Pi 4 + Pico), hardware-in-the-loop motor identification, closed-loop PID velocity control, Line of Sight (LOS) waypoint navigation, and live RViz odometry telemetry.
5. **Hardware-In-The-Loop (HIL) Flight Controller Testbench** — Real-time sensor simulation with FreeRTOS and CAN bus telemetry for fail-safe flight control verification.
6. **Marine ROV Submersible Prototype** — Watertight hydrostatic hull, vectored brushless thrusters matrix, subsea sensor acquisition, and real-time PC control telemetry via umbilical RS-485.

## 🛠️ Tech Stack & Architecture

- **Frontend Core**: Semantic HTML5, Vanilla JavaScript (ES modules)
- **Styling**: Tailwind CSS v4 with bespoke technical dark-mode theme & glassmorphic aesthetics
- **Build System**: Vite 6
- **Internationalization (i18n)**: Seamless dynamic switching across English (EN), Spanish (ES), and Italian (IT)
- **Deployment**: Automated continuous integration and deployment with GitHub Pages & GitHub Actions

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/fvelillah/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
